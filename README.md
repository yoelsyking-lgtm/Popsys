# CustomDialer

1. Abre Android Studio (Koala o más reciente) -> File > Open -> selecciona esta carpeta.
2. Espera a que termine "Gradle Sync" (necesita internet la primera vez).
3. Conecta un teléfono con depuración USB (o crea un emulador) y pulsa Run.
4. Para un APK: Build > Build Bundle(s) / APK(s) > Build APK(s).
